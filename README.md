# ploutos-gate

Utility libraries for **S**earch **E**ngine **O**ptimization (SEO),
**A**nswer **E**ngine **O**ptimization (AEO), and
**G**enerative **E**ngine **O**ptimization (GEO).

A collection of reusable utilities for optimizing content across traditional
search engines, AI answer engines, and generative AI platforms. Domain
packages live under the `ploutos_gate` namespace.

## Packages

- `ploutos_gate/mcp/reddit/` — Reddit MCP server with tools for search,
  browse, info, write, and monitor operations.

## Getting started

```bash
.venv/bin/python -m ensurepip
.venv/bin/pip install -e .
```
